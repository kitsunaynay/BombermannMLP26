# Additional experiments

This folder contains additional code and results from experiments conducted
during the project.

The folder contains:
- `agents/`: additional agent code used in the experiments
- `tools/`: training, checkpoint selection, evaluation, and analysis scripts
- `experiments/`: results and documentation from the additional experiments

These files were accidentally not included in the repository before the
submission deadline and were uploaded afterwards for completeness.

No changes to the submitted agent were made as part of this upload.
