# Additional experiments

This folder contains additional code and results from experiments conducted
during the project.

The files include:
- training code for the PPO control and survival-feature experiments
- the CNN Double DQN implementation and training code
- checkpoint selection and evaluation tools
- results from the PPO vs. Double DQN experiments

These files were used for the additional experiments.
They were accidentally not included in the repository before the submission
deadline and were uploaded afterwards for completeness.

No changes to the submitted agent were made as part of this upload.
